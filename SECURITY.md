# Security Policy

## Reporting a Vulnerability

We take the security and integrity of the SafeReach Emergency Platform seriously. If you find a security bug or vulnerability (such as potential SQL injection, authentication bypasses, or token leakage), please report it responsibly by following these steps:

1. **Do Not Open a Public Issue**: Please do not publish the vulnerability details on public trackers or social media.
2. **Submit a Report**: Send a detailed email outlining the issue, steps to reproduce, and impact to: `security@safereach.com`.
3. **Acknowledgment**: We will review and acknowledge your report within 48 hours and work on a resolution.

Thank you for helping keep SafeReach secure!
